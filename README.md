# KirpichVisuals 1.1.0 — Minecraft 1.21.4

Клиентский Fabric-мод с лёгким PvP HUD и визуальными эффектами.

## Что обновлено
- Новый единый стиль HUD: тёмные панели, тонкие контуры, цветной акцент.
- Target HUD: более широкая панель, плавная шкала здоровья, броня и поглощение.
- Potion HUD: заголовок, компактные строки и таймеры; список обновляется не чаще 10 раз/с.
- Cooldown HUD: заголовок, предметные иконки и полосы перезарядки.
- Убраны временные массивы координат при каждом HUD-кадре.
- Cooldown HUD больше не создаёт отдельный объект Entry для каждой строки на каждом кадре.
- Уменьшены значения по умолчанию для частиц: 8 за удар, дистанция 32 блока, адаптация при FPS ниже 60.
- Нет blur, тяжёлых шейдеров, внешних библиотек и фоновых потоков.

## Управление
- Right Shift — настройки.
- Настройки сохраняются в `config/kirpichvisuals.json`.

## Сборка
Требуется Java 21 и Gradle 8.10+ с доступом к Maven/Gradle репозиториям.
Выполнить `gradle build`. Готовый JAR будет в `build/libs/`.

Проект рассчитан на Fabric Loader 0.16+, Fabric API для 1.21.4 и Minecraft 1.21.4.
